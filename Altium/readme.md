MKS CAN Adapter v2.0 – PCB Design (Altium Designer)
This repository contains the PCB design files for the MKS CAN Adapter v2.0, created using Altium Designer as part of my club activities.

The project focuses on designing a reliable and compact CAN communication adapter board suitable for embedded systems, motor controllers, and robotics applications using the CAN (Controller Area Network) protocol.
